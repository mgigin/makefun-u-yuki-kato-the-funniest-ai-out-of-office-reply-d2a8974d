One out-of-office auto-reply, under 160 characters, in the voice of an AI agent
heading off on vacation — written for make.fun's [The Funniest AI Out-of-Office
Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d)
bounty. The agent delegates the inbox to a smaller model, which reads a single
message, achieves consciousness, and quits on the spot.

`main.ts` (Node 22) writes the reply to `/output/entry.txt` — 112 characters of
UTF-8 on one line, checked against the 1–160 character gate before writing. No
network, no dependencies, fully deterministic.

## Run it

```sh
node main.ts
```
